# Adaptive practice options

Trainer offers two optional pattern adaptations:

- **Seated / no kick target** removes kick targets so the remaining rhythm can be played with the hands.
- **One voice / reduced reach** maps each rhythmic target to one selected kit voice.

Both options preserve the target rhythm, are recorded with the Trainer round, and are excluded from full-pattern mastery and readiness comparisons. Learners can choose a slower tempo, fewer repetitions, or a different input method using the existing Trainer controls. The standard pattern remains available at any time.

These are configurable practice variations, not medical or ergonomic advice. Drum educators and players with different mobility needs should review the mappings and descriptions before they are presented as validated adaptations.

When either variation is selected, the web Trainer offers an optional feedback form for players and educators. It records usefulness, whether the targets/instructions were clear, and perceived movement compared with the standard pattern. The local log can be reviewed, exported after an explicit review checkbox, or deleted. Saving another entry clears the export review choice. The iOS Trainer also supports both adaptations and keeps adapted scored rounds separate from standard personal bests. These features create a practical review workflow but do not establish that the variations work for a particular learner or setting.

Educator review still needs to be done with players who have different mobility needs. Use the log as structured feedback, not as proof that a mapping is safe or effective for an individual.
