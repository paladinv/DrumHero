# Drum Hero for Android

This is an offline Kotlin/Compose starter targeting Android API 35. Open the `android/` directory in Android Studio with Android SDK 35 installed. From a shell, build it with `./gradlew :app:assembleDebug`; the wrapper uses Gradle 8.9 and resolves the Android and Compose plugins from the configured repositories.

The app reads lessons and groove patterns from `shared/mobile/v1/drum-content.json`, loads the existing drum WAV assets, and offers lesson browsing, four-bar score-led practice, five touch pads, tempo control, timing feedback, and recent local scores. Lesson completions and scored practice records use a local SQLite database, with one-time migration from the original SharedPreferences data. Practice can also receive USB or Bluetooth MIDI drum input, maps General MIDI percussion notes to the five scored voices, and saves an eight-click median timing correction per MIDI port. Bluetooth discovery asks for Nearby devices permission on Android 12+ or Location permission on older Android releases; touch scoring remains available without a MIDI device.

Progress can be exported to or imported from the reviewed `drum-hero-learning-archive-v1` JSON format. Android merges its supported lessons, Practice Pad sessions, best scores, and tempo, while retaining imported ear-training, Trainer, song, groove, guided-session, and weekly-goal fields for round-trip export. Audio, device calibration, and account credentials are never included.

This remains an initial native slice, not full feature parity. Microphone scoring, account sync, Android reminders, Song Library workflows, and complete feature parity remain open. MIDI calibration is an experimental personal correction, not a certified latency measurement; validate it with physical USB and Bluetooth kits before relying on scores. TalkBack and device timing review also remain open. The SQLite store is isolated behind `DrumProgressStore` so it can migrate to Room without changing screen behavior.
