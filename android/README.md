# Drum Hero for Android

This is an offline Kotlin/Compose starter targeting Android API 35. Open the `android/` directory in Android Studio with Android SDK 35 installed. From a shell, build it with `./gradlew :app:assembleDebug`; the wrapper uses Gradle 8.9 and resolves the Android and Compose plugins from the configured repositories.

The app reads lessons and groove patterns from `shared/mobile/v1/drum-content.json`, loads the existing drum WAV assets, and offers lesson browsing, four-bar score-led practice, five touch pads, tempo control, timing feedback, and recent local scores. Lesson completions and scored practice records use a local SQLite database, with one-time migration from the original SharedPreferences data. Practice can receive USB or Bluetooth MIDI input, maps General MIDI percussion notes to the five scored voices, and saves an eight-click median timing correction per MIDI port. A permission-gated single-voice microphone mode measures room noise, detects level changes for the selected voice, and processes audio in memory without recording or saving it. Bluetooth discovery asks for Nearby devices permission on Android 12+ or Location permission on older Android releases; touch scoring remains available without MIDI or microphone permission.

The Songs tab browses personal charts imported in a learning archive. It shows notation before controls and sends an individual score bar to Trainer for focused repetition. The Progress tab offers an optional daily local notification around a chosen local time; it stores only the reminder schedule and can be disabled at any time. The chart list and practice summaries stay local; full Song Library editing, recordings, setlists, and account sync are not available in this Android slice yet.

The Sight tab provides native drum-score reading with a silent preview, count-in, moving cursor, and touch or MIDI input. It supports 1–32 bars, beginner through advanced meters, target playback marked as assisted, reusable one-measure templates, and a separate 100-attempt history. Advanced readers can enable velocity scoring with per-voice soft/accent calibration on the selected MIDI device. Silent first reads feed interval-based review suggestions; repeated barline, grouping, offbeat, after-rest, and voice-change errors can start two-bar focused drills. Attempts and templates travel in learning archives; MIDI calibration remains local to the device.

Progress can be exported to or imported from the reviewed `drum-hero-learning-archive-v1` JSON format. Android merges its supported lessons, Practice Pad sessions, best scores, and tempo, while retaining imported ear-training, Trainer, song, groove, guided-session, and weekly-goal fields for round-trip export. Audio, device calibration, and account credentials are never included.

This remains an initial native slice, not full feature parity. Account sync, complete Song Library editing, Room/DataStore migration, and several web/iOS practice modes remain open. MIDI correction and microphone onset scoring are experimental personal tools, not certified measurements; validate them with physical kits and rooms before relying on scores. TalkBack and device timing review also remain open. The SQLite store is isolated behind `DrumProgressStore` so it can migrate to Room without changing screen behavior.
